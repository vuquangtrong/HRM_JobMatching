# HRM Tools

## Sub-projects

- `HRM_Extension`: a Chrome/Edge extension to auto interact with HRM page
- `HRM_Backend`: a backend for HRM_Extension to process and return data to show on HRM page

## Rules

- Can use colors to indicate status
- Do not generate icons in code
- Do not use inline styles, make css class and use it. try to keep minimal number of classes, based on less styles and elements to make minial UI layout.

## Testing

- HRM_Backend has its own python virtual environment, go to HRM_Backend and activate it. read setup_backend.sh for more details.
